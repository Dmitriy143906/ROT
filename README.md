# RØT Clan Website — JPG background version

Эта версия использует фон `static/rot-banner.jpg`.

Почему JPG:
- файл заметно меньше PNG;
- проще загружается через GitHub;
- браузеры и Render стабильно отдают его как обычную картинку.

## Внутри static
- index.html
- app.js
- styles.css
- rot-banner.jpg
- rot-logo.jpg

После загрузки на GitHub проверь:
https://rot-clan.onrender.com/static/rot-banner.jpg

Если изображение открывается — фон на главной тоже будет работать.
